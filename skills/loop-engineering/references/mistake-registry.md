# Mistake Registry — NEVER AGAIN list (general engineering)

Employee 3 FAILS any output that repeats a swept item here. Employee 1 verifies every `core` item and every item matching the task's tags BEFORE handoff; Employee 3 re-verifies with evidence. Append every new trap discovered in a loop, with its tags (add a new tag to the legend only when no existing one fits).

## How to sweep this registry

Every entry carries tags. **Always sweep `core`.** Then sweep every tag the task touches. When unsure whether a tag applies, include it, and list the tags you swept in the evidence. Entry IDs such as E1 or E3 below are registry IDs, not the Employees.

| Tag | Sweep it when the task… |
|---|---|
| `core` | always |
| `ui` | renders anything a person looks at (web page, app screen, email, PDF) or animates |
| `data` | reads or writes a database, migrations, derived records, exports, or money figures |
| `test` | writes or runs tests, mutation checks, or CI |
| `ops` | runs, deploys, packages, backs up or stops processes, or touches a live system |
| `security` | touches auth, sessions, permissions, or outside input that reaches code or files |
| `env` | uses the shell, the editor's file tools, Windows/PowerShell, or text encodings (almost every task, so `core` + `env` is the usual minimum) |
